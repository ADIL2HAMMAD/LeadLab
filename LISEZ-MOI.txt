LEADLAB — PRÉPARATION TECH LEAD / FULLSTACK
Java · Spring Boot · React / TypeScript
Édition du 13 octobre 2026

OUVRIR LE SITE
1. Extrayez tout le ZIP dans un dossier.
2. Ouvrez index.html avec un navigateur moderne (Edge, Chrome, Firefox…).
3. Gardez index.html, styles.css, data.js, app.js ainsi que les dossiers assets et content ensemble.
Aucune installation, connexion Internet ou dépendance serveur n’est nécessaire.
Le site fonctionne avec des scripts classiques, sans requête de chargement de données.

CONTENU
- 16 modules : Java, Spring Boot, JPA, Sécurité, React/TypeScript, architecture, Tests/DevOps,
  leadership, Debugging, Live coding, Scénarios de production, API, Performance,
  System design, IA & génie logiciel, Questions pièges Senior.
- 745 fiches détaillées : explications, exemples, pièges et relances.
- 745 questions de quiz, ordre et choix mélangés, corrections détaillées,
  bilan, historique et possibilité de rejouer ses erreurs.
- Planning de 14 jours avec exercices, livrables et dates ajustables.
- Entretien blanc : 4, 6 ou 8 questions, chronomètre de 20, 30 ou 40 minutes,
  4 mises en situation dans la banque, notes et auto-évaluation sur 4 critères.
- Recherche, filtres, favoris, notes et suivi de progression.
- Recherche simple : un mot + module, niveau et progression ; résultats par lots de 25.

PROGRESSION ET SAUVEGARDES
La progression est enregistrée dans le stockage local du navigateur.
Elle est propre au navigateur et à l’adresse utilisée pour ouvrir le site.
Le comportement de localStorage sur les fichiers locaux dépend du navigateur.
Une ouverture directe (file://), un aperçu HTTP et un autre emplacement
peuvent avoir des stockages distincts. Le mode privé peut effacer les données
à sa fermeture. Si le stockage est indisponible, un bandeau le signale.

Dans « Mes données », exportez régulièrement votre progression en JSON.
Vous pourrez l’importer sur un autre navigateur ou après déplacement du dossier.
L’import remplace les données existantes après confirmation.
La réinitialisation ne concerne que les données LeadLab de ce navigateur.
Les 100 derniers quiz et 50 derniers entretiens sont conservés.
Les réponses écrites restent sur votre appareil ; aucun service ne les analyse.

COMMENT S’ENTRAÎNER
1. Formulez une réponse à voix haute avant d’ouvrir la fiche.
2. Comparez votre réponse au mécanisme, exemple et piège présentés.
3. Notez un exemple issu de votre expérience et préparez les relances.
4. Validez une fiche seulement si vous pouvez la reformuler sans aide.
5. Faites un quiz, revoyez vos erreurs puis réalisez l’exercice du jour.
6. En simulation, répondez avant de révéler les attendus, puis auto-évaluez-vous.

Le planning cible les fondamentaux ; les fiches supplémentaires permettent
un approfondissement à votre rythme. Les anciens identifiants sont conservés.
Les scores de quiz et la maîtrise déclarée des fiches sont distincts.
Le score d’entretien est une auto-évaluation, pas une notation automatique.
Le chronomètre est indicatif : vous pouvez continuer après son expiration.
Quitter la page d’entretien met le chronomètre en pause.

EXEMPLES ET RÉFÉRENCES
Les exemples de code sont pédagogiques et peuvent omettre imports et types.
Le site ne compile ni n’exécute le code des exercices.
Le socle vise Java 17+ ; les threads virtuels nécessitent Java 21+.
Vérifiez les signatures et options selon les versions exactes de votre projet.
Les liens de la page « Références & méthode » nécessitent Internet ;
tout le contenu de préparation est déjà embarqué dans le dossier.
